# 全屏时间轴拖动偏移修复

日期：2026-10-29。修复基线：c991982；回退分支：checkpoint/before-fullscreen-fix-20261029。

## 原因与修复

MapLibre 在全屏、窗口尺寸或像素比例变化时更新共享画布。Three.js 在初始化时缓存默认视口，而阴影贴图通道完成后会恢复这个缓存。旧代码没有同步它，导致白天拖动时间轴触发阴影更新时恢复旧尺寸，建筑画面被压缩并向左偏移；夜间关闭阴影，没有触发该恢复路径。

修复仅在每次建筑绘制前，将 Three.js 默认视口同步为当前 WebGL 绘图缓冲区大小，并正确换算 renderer 的像素比例。没有调用会改写共享画布的 setSize，也没有改变相机、建筑坐标或阴影算法。增加视口与绘图缓冲区诊断字段以便复核。
