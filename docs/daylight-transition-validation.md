# 连续日夜光色变化

日期：2026-10-29。基线：749ba49；回退分支：checkpoint/before-daylight-transition-20261029。

之前仅以太阳高度大于零切换固定光源强度及 CSS 夜色滤镜，太阳跨过地平线时画面会突变。

现由同一个太阳高度函数连续计算方向光强度、太阳暖色到中性色、环境光强度和色调、地图亮度/饱和度/暖色、地面阴影不透明度及太阳标记淡出。保留真实太阳方向和几何阴影；太阳位于地平线以下仍关闭太阳阴影，但关闭前强度已经平滑归零。环境光在 -12° 至 0° 区间提供晨昏过渡，再向日间光照变化。CSS 以 160ms 线性过渡吸收拖动步长造成的亮度差，尊重减少动态效果偏好。

这是视觉光照模型，不是大气散射、色温测量或地面照度计算。相同太阳高度采用相同参数，不依赖预设时刻，因此不同纬度、季节和极昼/极夜仍使用真实太阳位置驱动。

验证结果：

- 17 项测试通过，含亮度随太阳升高单调增加、暮光/地平线连续性、实际 BuildingLayer 光源与阴影淡出，以及之前的全屏视口回归测试。
- TypeScript 与生产构建通过。
- 真实浏览器纽约 2026-10-29：07:45 高度 3.3°，暖色、偏暗；太阳正午约 12:39 高度 35.7°，明显更亮；18:10 高度 -2.9° 保留暮光；19:15 高度约 -15°，渐入冷色夜景。
- 连续输入 17:50、17:52、17:53、17:54、17:56、18:10，越过地平线时地图亮度系数从约 0.516 到 0.514，环境光从 0.720013 到 0.719996，阴影不透明度在关闭前已降至约 0.00012，未出现昼夜开关式跳变。
- 全屏实际拖动时间轴从夜间返回 13:14，视口和绘图缓冲区均为 2560×1440，建筑与地图对齐。相机中心不变，建筑请求 0 次、构建 1 次。
- 输出保存清晨、正午、暮光、夜间截图和逐时光照参数 JSON。
