## 已知限制与待补验项

- 全屏按钮已尝试，但当前内置浏览器未取得可靠的进入全屏证据；仍需普通浏览器实测。WebGL 2 不可用提示已实现，但没有在禁用 WebGL 的浏览器环境中验证。
- 网络失败提示在恢复过程实际出现且重试成功。429 限流、搜索无结果和 WebGL 丢失尚未逐项做浏览器故障注入；不能把单元测试等同于全部端到端故障验收。
- 公共服务有超时与限流风险；之前伦敦请求曾失败后重试成功。无付费 SLA，未承诺中国大陆网络或中文地址完整覆盖。
- 开发服务日志出现底图道路编号图层的空属性警告（number 为 null，过滤器回退 false）；地图和建筑仍正常显示，个别道路编号可能不显示。未为此修改第三方底图样式。
- 建筑轮廓、高度及分段完整性取决于 OSM；标注高度不是实测认证。外壳与分段去重采用空间包含启发式，不是完整建筑关系重建；可能省略未被分段覆盖的外壳部分。
- 水平地面、简化屋顶；当前只有固定展示光照。太阳、时区、阴影、日期/时间轴、播放均未实现。
- 地图按中心附近约 900 × 900 米加载；远处只有底图，已显示数据范围。默认摘录关联对象可能超出请求边界。
- 构建主脚本约 1.68 MB，gzip 约 450 KB；独立地图 worker 约 519 KB。构建有大包警告，未冒充为加载性能已经全面优化。
- 没有修改数据库、Supabase、远程仓库或正式站点。

## 数据与交付

- 底图：OpenFreeMap / OpenMapTiles，包含 OpenStreetMap 数据署名。
- 搜索：Photon，点击提交时查询，不做自动补全。
- 在线建筑：VK Maps 的 Overpass 实例；每客户端查询间隔至少 5 秒，缓存最多 8 个区域，移动结束后去抖，取消过时请求。
- 默认摘录：2026-10-27 获取的真实 OSM API 数据，来源、范围、许可和推断方法见 `public/data/README.md`。未重新生成或覆盖摘录。
- 输出目录保存桌面/移动端截图、10 次切换诊断 JSON、源码包、静态构建包和本记录副本。源码包不包含 node_modules、私密环境变量或 Git 历史；本地仓库保留回退提交。
