# GeoLab

真实城市太阳与建筑阴影模拟器。阶段 1 地图与建筑、阶段 2 双时间轴、当地时间、太阳轨迹及真实几何阴影已实现并在本地验证；尚未部署。阶段 3 的全面性能优化与更多设备验证尚未开始。

## 本地运行

使用 Node.js 24 或更新版本：

```sh
npm ci
npm run dev
```

开发地址见终端输出。`npm run build` 做 TypeScript 检查并生成 `dist/`，`npm run preview` 查看生产构建，`npm test` 验证高度、坐标、建筑分段及数据请求行为。

## 使用

- 默认展示纽约 Bryant Park 周边的真实 OSM 建筑摘录。
- 搜索框输入城市、街道地址，点击搜索后选择结果。坐标格式为 **纬度, 经度**，例如 `51.50745, -0.12777`。
- 拖动平移，滚轮缩放，右键拖动旋转/倾斜；底部可切换俯视、透视，调整倾角。右侧按钮支持正北、缩放、重置和全屏。
- 点击三维建筑查看高度、推断方法、底部离地高度和 OSM 原始对象链接。
- 开启“区分高度来源”查看数据标注、按层数估算和默认估算。建筑统计按体块（含建筑分段）计数，不是独立楼宇数量。
- 打开“数据与精度说明”，可在线更新当前区域。
- 底部日期轴覆盖当前年份，支持日期选择、闰年以及按年计算的春分/夏至/秋分/冬至快捷键（北半球命名）。改日期保留当地时刻；改时刻保留当地日期。
- 一天时间轴从本地当天起点到次日 00:00，按真实经过分钟移动；夏令时日期会显示 23/25 小时，半小时时区跳变也按实际长度处理。到 24:00 时模拟状态进入次日 00:00。
- 两个播放按钮互斥：全年每 0.25 秒前进一天、到年末停止；一天每 0.25 秒前进 10 分钟、到次日零点停止。编辑时间或切换地点暂停播放，切到后台也暂停。
- 初始为默认地点当天 14:00；“现在”跳到真实当前时刻。切换地点保留同一 UTC 时刻，自动换算当地时间；地图平移结束后以中心为观察位置。
- 自动识别 IANA 时区，可通过“时区”校正。缺失时刻按时区跳变长度向后顺延；重复时刻输入默认采用第一次，第二次可用时间轴选取，以 UTC 偏移区分。
- 日出、太阳正午、日落按钮可直接定位；可开关事件标记和太阳轨迹。夜间关闭太阳光与阴影，保留便于观察的环境光。

## 配置与数据

无需 key 的默认服务：OpenFreeMap / OpenMapTiles 底图、Photon 搜索、VK Maps Overpass 查询。可以复制 `.env.example` 为 `.env.local` 更换兼容端点；这些 `VITE_` 值会公开进入浏览器，**不得填入私密凭据**。

建筑请求限定为中心附近约 900 × 900 米；地图移动结束后去抖查询，相邻视野复用缓存，最多保留 8 个区域，单客户端请求间隔至少 5 秒。只在街区级别（zoom >= 15）请求建筑；同一地点的旋转、倾斜不会重新请求或重建场景。

地图与建筑源不同步更新时可能存在轻微差异。公共服务可能超时、限流，全球数据完整性不保证；适合低流量 MVP，扩大使用前应选择有保障的数据服务或自托管。没有自动轮换服务以绕过限流。

## 精度边界

有效 `height` 标记为**数据源标注**，不等于实测认证；`building:levels` 按每层 3 米估算；缺失时默认 9 米。支持米/英尺、`min_height`、`building:min_level`、Polygon / MultiPolygon、孔洞和 `building:part`。有分段的建筑外壳不重复拉伸。不完整关系被跳过，数量在数据说明中披露。

地面为水平面、屋顶为简化几何。SunCalc 2 计算含标准折射的太阳视位置；方向以正北为 0°、顺时针增加，再转换为东/北/上坐标。Three.js 用实际建筑几何生成 2048 × 2048 阴影贴图，建筑同时投影和接影，透明地面接影保留底图。

阴影只含已加载建筑及有限接影范围；低太阳高度的长阴影会截断，细小几何可能出现离散误差。日出日落是无遮挡海平面参考，不考虑建筑遮挡；太阳中心位于地平线以下时关闭阴影。没有天气、地形或室内照度模拟，不能作为精密工程日照认证。

经纬度时区查找使用压缩边界数据库，边界附近可能不准确；用户可手动校正。IANA 历史/夏令时规则由 Temporal 与浏览器 Intl 时区数据提供。支持界面日期范围 1900–2100；旧时区边界和未来规则变化仍需核验。

## 代码结构

| 目录/文件 | 职责 |
| --- | --- |
| `src/data.ts` | 搜索、缓存、限速、请求取消与数据来源 |
| `src/buildings.ts` | OSM 标准化、分段、高度与坐标解析 |
| `src/scene.ts` | Three.js 几何合批、地图坐标变换、点击拾取与资源释放 |
| `src/simulation.ts` | 唯一 UTC 时刻、当地日期/时刻、时区和夏令时规则 |
| `src/solar.ts` | SunCalc 2 太阳方向、日出日落、轨迹及 Astronomy Engine 节气 |
| `src/timeline.ts` | 日期/时间轴、播放状态、太阳信息与时区校正 |
| `src/main.ts` | 地图生命周期与界面交互 |
| `src/style.css` | 响应式悬浮面板与视觉样式 |
| `public/data/` | 带来源与许可的真实默认区域摘录 |

规划见 [implementation-plan.md](docs/implementation-plan.md)，实际验证记录见 [阶段 1](docs/phase-1-validation.md) 和 [阶段 2](docs/phase-2-validation.md)。
